Configurar acesso

Para usar o admin online precisas de um GitHub Personal Access Token com permissão de escrita neste repositório.

O token fica guardado apenas neste browser — nunca vai para o GitHub nem para nenhum servidor. Só tu tens acesso a ele.

Como criar o token:
1. Vai a github.com/settings/tokens/new
2. Note: escreve "Painel de Preços"
3. Expiration: escolhe "No expiration" ou 1 ano
4. Em "Repository access" → "Only select repositories" → seleciona preco_reparacoes
5. Em Permissions → "Contents" → Read and write
6. Em Permissions → "Actions" → Read and write (necessário para o botão "Atualizar preços")
7. Clica "Generate token" → copia o token gerado (começa com ghp_)
8. Cola aqui em cima e clica "Guardar e entrar"
